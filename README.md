# 🇱🇰 SERENDIB — Discover Sri Lanka | The Island Beyond

> An ultra-premium, cinematic digital travel showcase & journey planner for Sri Lanka — featuring interactive maps, heritage explorations, wildlife expeditions, coastal guides, tea country trails, culinary journeys, and an interactive itinerary generator.

---

## ✨ Features & Experiences

- 🏛️ **Sacred Heritage & UNESCO Citadels** — Sigiriya Rock Fortress, Temple of the Sacred Tooth Relic, Anuradhapura Sacred Kingdom, Polonnaruwa Medieval Capital, Dambulla Cave Temples, and Galle Dutch Fort.
- 🌊 **Coastlines & Surf Sanctuaries** — In-depth guides to Mirissa, Unawatuna, Hiriketiya, Bentota, Arugam Bay, Nilaveli, and Trincomalee with seasonal surfing and water temperature insights.
- 🚂 **Highland Mountain Railways & Tea Estates** — Demodara Nine Arch Viaduct, Horton Plains World’s End, Knuckles Massif, and Lipton’s Seat.
- 🐆 **Wild Sanctuaries & Marine Megafauna** — Sri Lankan Leopards, Asian Elephant Gatherings in Minneriya, Sloth Bears in Wilpattu, and Blue Whales in the deep oceanic trenches.
- 🍛 **Ceylon Culinary Explorer** — Traditional Rice & Curry banquets, Egg Hoppers, Kottu Roti, String Hoppers, Dutch Burgher Lamprais, Pol Sambol, and Watalappam.
- 🗺️ **Interactive Destination Map & Region Explorer** — Visual map coordinates, climate information, elevation stats, and regional cultural overviews.
- 🧭 **Intelligent Multi-Day Journey Planner** — Customizable itinerary generator tailored to duration, travel styles, and bucket-list experiences.
- ⚙️ **Media & Content Control System** — Integrated admin panel for real-time image updates and persistent customizations.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Build Tool**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Cinzel, Cormorant Garamond, Plus Jakarta Sans

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/serendib-sri-lanka.git

# Navigate to project directory
cd serendib-sri-lanka

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
